# Uber Eats 2025 Clone (Front-End)

A simple, modern, and fully responsive *Uber Eats 2025 Front-End Web Clone* created using React (JSX). This project recreates the look and feel of the official 2025 Uber Eats website.

---

##  About The Project

This project focuses on building the user interface (UI) of the Uber Eats website. It includes the main home page layout, dynamic navigation, and login/sign-up forms. The layout works smoothly on all screen sizes, including mobile phones, tablets, and desktop computers.

---

##  Features

- *Home Page:* Displays the 2025 Uber Eats home layout with food categories and promotional banners.
- *Header & Sidebar:* Includes top navigation bar along with a functional slide-out side menu.
- *Login & Sign-Up Page:* Clean and stylish user interface for login and registration forms.
- *Footer:* Full footer section added directly inside the home page for links, app info, and legal notes.
- *Visual Map Preview:* Uses a fast, lightweight static map preview image instead of live API tracking to keep the design clean and quick to load.
- *Fully Responsive:* Looks great on desktops, tablets, and mobile screens.

---

##  Project Components

The website is divided into three main React components:

| Component | Description |
| :--- | :--- |
| *Header.jsx* | Contains top navigation, search UI, branding, and the slide-out sidebar menu. |
| *Home.jsx* | Contains the complete home page contents,  map preview, and the footer section. |
| *Login.jsx* | Contains both the *Login* and *Sign-Up* form designs. |

---

##  Tech Stack

- *Front-End:* React.js (.jsx)
- *Styling:* CSS3
- *Design:* Simple and Responsive Web Design
